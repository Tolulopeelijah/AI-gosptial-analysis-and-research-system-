## Composability

Tools consume GeoJSON FeatureCollections, tables, rasters (file descriptors), networks, or coordinates, and return typed envelopes (`ok`, `type`, payload, `crs`, metadata). Intermediate results chain through `$step_id` references resolved by the orchestrator; large payloads never enter the LLM prompt (summaries only).

## Mock / live behaviour

ArcGIS datasets serve mock fixtures while `ARCGIS_USE_MOCK=true`, flagged `mocked: true` with `provisional_schema: true` and the real `live_urls`. Provider tools (Overpass, Nominatim, Open-Meteo, GBIF, STAC, WFS) need network and fail with explicit capability errors when unreachable.
